DMX Controller - RY-AI Bluetooth box (USB-RDM-DMX)
===================================================

ENGLISH
-------
1. Pair the Bluetooth box in Windows, then start DmxController.exe
   (nothing to install; if SmartScreen warns, click "More info" > "Run anyway").
2. Pick the box's "outgoing" COM port in the connection bar, then Connect.
3. Example configurations are in the "Examples" folder:
   File > Open / import, then pick one of them.
   - "Soirée par défaut.dmxshow_3.dmxshow.json": the full set-up
     (2 Intimidator Spot 260X moving heads, Mini Spider, UV PAR, Galactic laser, Ayra fog machine)
   - the two others: earlier versions (moving heads + Spider)
   Check that the DMX addresses in Fixtures > Patch match the menu of your fixtures.
4. Language: Settings > Langue / Language (English by default, French available).
Your own configurations are saved in %APPDATA%\DmxController\Configurations.

FRANÇAIS
--------
1. Appaire le boîtier Bluetooth dans Windows, puis lance DmxController.exe
   (rien à installer ; si SmartScreen avertit : « Informations complémentaires » > « Exécuter quand même »).
2. Choisis le port COM « sortant » du boîtier dans la barre de connexion, puis Connecter.
3. Des configurations d'exemple sont dans le dossier « Examples » :
   Fichier > Ouvrir / importer, puis choisis-en une.
   - « Soirée par défaut.dmxshow_3.dmxshow.json » : l'installation complète
     (2 lyres Intimidator Spot 260X, Mini Spider, PAR UV, laser Galactic, fumée Ayra)
   - les deux autres : versions précédentes (lyres + Spider)
   Vérifie que les adresses DMX (Appareils > Patch) correspondent au menu de tes appareils.
4. Langue : Paramètres > Langue / Language (anglais par défaut, français disponible).
Tes propres configurations sont enregistrées dans %APPDATA%\DmxController\Configurations.
